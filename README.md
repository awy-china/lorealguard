# LorealGuard · 信任守护师

[![CI](https://github.com/awy-china/lorealguard/actions/workflows/ci.yml/badge.svg)](https://github.com/awy-china/lorealguard/actions/workflows/ci.yml) [![License: Apache 2.0](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)

> 欧莱雅「美妆科技黑客松」赛题2 参赛工程 —— **美妆内容真实性核验**
> 核心命题：平台要替用户判断「这张种草图到底动过没有」，但**误伤真实创作者的代价，远大于漏判**。

## 一句话定位

**我们不判真假，我们出一本可复算的账。**

大模型不碰「是不是假的」这个判断：坐标由算法给，语义由模型给。这条主张的四个面：

- **判定不用模型** —— 判定链零模型调用；模型只解释已定位的疑点，绝不给真假结论。
- **图不出本机** —— 默认路径零模型、零网络，核验全程在本机完成。
- **结论可复算** —— 同一输入、同一规则表，判定逐字节可复现；自证包附哈希锚与规则表指纹，外人可自行复算。
- **创作者可申诉** —— 报告右栏是申诉材料的正文，不是免责声明。

## 产品主张的代码形态：双向账本

我们交付的不是「一个检测器」，而是**一份两栏并列的报告**：

```
┌──────────────────────────────┬──────────────────────────────┐
│ 一、可疑证据（左半栏）         │ 二、免责与良性归因（右半栏）    │
│ 坐标 / 极性 / 形态 / 数字      │ 为什么不该怀疑你 + 它解释了哪几条 │
└──────────────────────────────┴──────────────────────────────┘
```

行业里的可解释性大多停在热力图 —— 热力图能说「哪里怪」，说不了「为什么这么判、依据哪一条」。
所以本项目把三件事写进了**类型**（不是文档）：

1. **免责证据与可疑证据同为一等公民** —— 报告不允许只报前者（`core/contract.py` 的 `BenignEvidence`）。
2. **每条结论必须带出处** —— 法条 / 平台规则 / 检测器，无出处不许进报告（`SourceRef`）。
3. **「不确定」是合法结论** —— 缺证据时必须能弃权，禁止用 0 分冒充「清白」（`ProvenanceState.UNKNOWN`、`RiskTier.UNDETERMINED`）。

## 阈值住在规则表里，不住在代码里

F7 是唯一能改变判定结果的地方，所以它被单独抽出来：

```
voiceguard/rules/
  rules.yaml     7 条风险规则 + 7 条免责规则；每条带 source（法条条号 / 检测器）+ 标定口径
  engine.py      纯机制：怎么比、什么时候不判。**代码里没有任何一个阈值数字**（有测试锁死）
```

于是三件事可以分别做：改判定标准 = 改表；改判定机制 = 改代码；查判定依据 = 读报告第四节的「触发时实测值」。

规则表自带体检（`rules.selfcheck`）：拿「刚好满足」的合成信号把每条规则各点一次火，
把 typo（未知运算符 / 未知等级 / 未知法条键）逼出来 —— 否则规则会静默失效，而报告照样显示「已跑」。

## 实测结论（每一行都有脚本可复现）

1. **ELA 的重压缩质量 q 必须低于原图自身质量。**
   实测：同一张磨皮图，`q=95`（≈相机自身质量）时磨皮区残差由 0.40 升到 1.10、**高于周边**，
   极性变成「偏亮」，**被伪装成拼接**；`q=90` 时转为「偏暗」，方向才正确。
   机理：q ≈ 原图质量 → 双压缩失配消失 → 被改动的像素成为唯一残差来源 → 残差反升。

2. **头号误报是「美颜」，它必须被降权而不是被检出。**
   磨皮在 `q≤90` 下只让区域 ELA 降约 1σ（区域均值 z≈−1.0），远达不到稳健 z 阈值 4。
   极性加权 `w_pos=1.0 / w_neg=0.33` 是第二道防线；第一道是 q 选择。
   要检出磨皮必须另加高频/噪声检测器（P1），不能指望 ELA。

3. **「不适用」≠「无异常」。** PNG/截图无 JPEG 压缩史时 ELA 没有区分度，必须返回 `confidence=low`，
   并**不得给出任何评价性结论**（说「未检出异常块」会被顺读成「没篡改」）。

4. **ELA 看不见「同图复制粘贴」（copy-move）。** 缩放裁切同一张图再贴上去，压缩史与周围一致 → 残差无差异。
   这是 P1 复制粘贴检测器存在的理由，不是 ELA 的 bug（已写成测试防后人误「修」）。

5. **ELA 对「同源提亮」无感；有效信号是噪声场不匹配。**（`_diag_splice_sensitivity.py` 全表扫描）
   - 纯提亮：gain 从 1.00 到 2.00 —— **全部检不出**。
   - 叠加异源噪声 σ≥4：稳定检出，峰值 z≈9.5~10.7、**IoU 0.85~0.89**。
   - gain ≥1.6 且 σ≥8：z 很高（14~16）但 **IoU 崩到 0.06~0.10** —— **z 高 ≠ 定位准**，两件事必须分开报。

8. **「降权」必须覆盖所有出口，否则等于没降权。** P2 首轮误报（b03）根因：检测器发现平台重压缩后
   把 `score` 乘 0.3，但区域列表没降权；规则改用坐标级证据触发后绕过了那道降权 → 冤枉一张正常图。
   现在「检测器可靠性」是一等信号（`forensics.<name>.reliable`），由规则显式要求 `== true`。

9. **面积加权分不能当触发条件。** 它把「区域多大」混进「有多可疑」：8.8% 面积的跨源拼接只得 `score=0.586`，
   卡在 0.6 阈值下 → 报告出现「左栏有证据、判定说未触发」的自相矛盾。触发条件必须是**坐标级证据本身**。
   现由 `test_left_column_implies_a_risk_rule_fires` 锁死。

7. **证据 JSON 不内嵌像素数组。** `ndarray.tolist()` 曾让一份报告 JSON 涨到 27~35 MB（人打不开、评审不会看）。
   现在数组压成「形状 + dtype + min/max/mean」描述符 —— 想知道细节就拿着报告里的参数重跑，这比从 JSON 捞像素更符合「可复现」。

10. **词典漏一个词，整句就"失明"。** 「彻底祛除色斑」曾因类别词典漏收「色斑」而被判成「无功效宣称」，
    于是图文交叉与弃权声明**两条通路同时关闭** —— 不报错、不告警，只是静默漏判。
    现在功效语境 = 类别词 **或** 强/绝对强度词（兜底）；词典每加一类，都要顺手问一次「漏了它整句会变成什么」。

11. **「没给我文案」≠「文案里没有功效宣称」。** 前者文本类信号必须是 `None`（规则不命中），后者才是 `False`。
    这两件事责任完全不同 —— 混起来会让纯图像样本被卷进文案规则。
    接入 F4 后重跑 P2：六项指标**一个都没变**，这正是这条纪律在起作用。

## P2：误报压力测试集与公开评测协议

产品主张是「不冤枉真实创作者」，所以评测的重心不是「抓到了多少」，而是
**「在所有会诱发误报的正常编辑上，我们错了几次、错得多重」**。

- **数据集 = 生成器 + 固定种子 + sha256 清单**（不分发图片文件）：**60 条工况 = 良性 40 + 恶意 20**，
  每条写下承诺（等级上限 / 应命中的规则 / 应给出的免责归因）。复现方式见 `samples/make_p2_suite.py`。
- ⚠️ **承诺先写下、再实测**：新增的 12 条恶意样本（m09–m20）在跑之前就按**独立于本集**的下界扫描
  （σ≥8 稳定检出）写下「应达关注级」，跑完 12/12 全部兑现；**跑不出来会如实登记为违规，绝不回头调阈值**。
- **六项指标，口径写在数字前面**：①误报率（<10%）②严重误报率（=0，硬门槛）③漏报率 ④**弃权率**
  ⑤定位 IoU 中位数 ⑥承诺兑现率。其中三条边界必须写清，否则指标可被无声做假：
  **弃权不算误报**（它= 没有足够证据，不是「判定为真」）、
  **已声明 AI 判「提示级」不算误报**（第六条（一）：加提示即可）、
  **「检测器不适用」必须与「无异常」分开报**。
- **v1 结果**（`output/p2/bench_report.md`，协议全文见 `D:\deliver\compete\loreal-p2-protocol.md`）：
  误报率 **0.0%**（0/40；**95% 置信上界 7.22% < 10% ✅**）
  —— 注意这是**自造集口径**：把规则表全文交给对手后，白盒陷害侧误报 69.7%（23/33）、红线被击穿 3 条（见下 P6）、
  严重误报 **0%**、承诺兑现 **60/60**、
  检出率 **75.0%（95%CI 50.9%~91.3%，下界站上 50%）**、漏报率 25.0%（5/20）、
  定位 IoU 中位数 **0.841**（n=15，13 种真值几何，极差 0.758~0.87）、弃权率 **71.7%**（附**按理由的分类分解**，见报告第七节）。
  ⚠️ 检出侧现在**同时给点估计与区间**，且单侧/双侧两种口径都印 —— 见报告第八节「口径不许挑」。
  **首轮是 4.8% / 28/29 —— 压力集当场抓到一例真误报**（详见下条）。
- **F4 接入后重跑（2026-09-19）：六项指标一字未变。** P2 是纯图像工况，文本层不参与
  （`text.*` 信号为 `None`，规则不命中）。要证明的不是"跑过了"，而是**"没有偷偷参与"**。
- ⚠️ 那句「文本层不参与」正是主集的**设计前提**，也是它的局限：60/60 条的免责归因都带
  `NO_TEXT_PROVIDED`，三道保守闸门在主报告里**触发 0 次**。所以另建了 **P2-T 文案通路配对集**：
  30 张良性图不变、每张配两套文案（合规话术 / 夸大功效），同一张图上只改文案 →
  等级差异归因于文案通路（每侧 **33 条 = 11 套文案 × 3 张图**，n 是按承诺倒推的）。
  结果：**文案通路误报 0/33（95% 上界 8.68% <10% ✅）**（同一自造集口径；对抗条件下白盒陷害侧
  误报 69.7%、红线击穿 3 条，见下 P6）、**严重误报 0%、
  检出 24/33（72.7%，95%CI 54.5%~86.7%）、配对翻转 24/30（9 条未翻转 = 3 类公告探针 × 3 张）**。
  **三道保守闸门全部被样本执行到（门① 3+3 / 门② 18+0 / 门③ 12+6）** —— 其中门①
  （下界为 0 永不判不可行）是 v3 专门补的活性样本：v2 时它触发 0/0，核心铁律**零覆盖**。
  图像通路另有 2 次命中，全部是 `R-AI-LABEL-DECLARED`
  （图自带 AI 标识声明 → 「提示级」，**不算误报**，如实分列）。
  报告：`output/p2/text_report.md`（跑分器 `experiments/p2_text_bench.py`，与主集**同一把尺**）。
- ⚠️ **协议修订留档**：P2-T v1 的承诺兑现是 **59/60**（唯一"违规"是探针配到带 AI 标识的图，
  图像轴合法发提示级）→ v2 只改期望、**不动任何检测逻辑与阈值**，v1 的 59/60 原样印在报告第六节。
- **已知盲区要公告**：同源提亮、copy-move、同源克隆、被剥离标识的 AI 图（需 P1 像素级生成痕迹检测器，
  当前必须弃权而不是硬判）；σ=4 登记为**边界样本**并公开两组口径差异。

> 为什么值得这么做：一个愿意公告自己检出下界、并且能被别人往里加样本的评测集，才叫标准；
> 只能自己往里加样本的，叫宣传材料。

## 边缘场景（误报护栏的证据）

官方评分第 2 位问「测试数据质量是否满足提交格式，**数据是否涵盖边缘场景**」
（赛题原文 `loreal-topic2-details.md:21`，原词）。**9 条**边缘样本正面回答它
（生成器 `samples/make_edge_suite.py` → `output/edge/` 图 + `manifest.json` + 逐条 `README.txt`）：

**平色底图**（观察栏须如实弃权，不许假装「无异常」）、**整图暖色温**、**同源九宫格拼版**、
**异源拼接标定图**（观察栏出真实接缝数字但**不改判定**）、**原位 q75 重压缩**、
**改尺寸 q75**（上一条的对照）、**裁剪 80%**、**加字幕条**、**64×64 极小图**。

- **如实登记（为什么不列「无 EXIF」那条）**：合成底图 `samples/base_neutral.jpg` 本身零 EXIF
  （实测 `getexif()` 条目数 = 0），再"剥离 EXIF"是空操作 ⇒ 产物与主集样本**逐字节相同**（同 sha256）
  ⇒ 会造出同哈希样本对；换任何算子又都会撞上主集已用过的算子（`case_rotate_slight` 不吃 rng，
  重造即同哈希）。该覆盖由主集全体样本天然承担，**不塞凑数的样本**。

- 它们**全是良性**、**不新增任何检出靶**：这是「误报护栏」的证据，不是检出集。
  每条 `expect.max_tier` 在看结果之前写死为**关注级**（关注级 = rank 2 ⇒ **不得判违规**）。
- ⚠️ **`edge_inplace_q75` 是我们主动交代的能力边界**（`docs/DEBT.md` D-12）：原位降质重压缩
  （几何未变）会被推上关注级 —— 那是**复核提示，不是判违规**；同质量、只多一步改尺寸的
  `edge_resized_q75` 信号更强反而不触发，分界线落在「几何是否变化」上，**不是**阈值松紧问题。
- 其中四张（平色 / 暖色 / 同源网格 / 异源拼接）**调用 `samples/calib_lighting_color.py` 的同名函数重造**
  （铁律 9：能从冻结语料重放），不是从 `samples/calib/` 拷进包里的现成 jpg。

## P6：红队实测 —— 把刀递给对手

前面所有数字都有一个软肋：**样本是我们自己写的**，我们（有意无意）避开了自己的刀。
P6 换一个方向：让对手**看到我们的规则表与全部数值门槛**，专门往「不冤枉人」上打。
协议先写死、测完不许改（`docs/REDTEAM-PROTOCOL.md`）；语料一次性封存
（`samples/red_team/red_team.json`，99 条线程），跑分器只读它、**靶子指纹不符就拒绝出分**（exit 3）。

| 矛 | 对手 | n | 读数 |
|---|---|---|---|
| **A 规避** `evade` | 白盒：拿到全部阈值 | 33 | **绕过 100%**（检出 0/33，下界 0%）—— 它交出的是零重复、零商业符号、细节齐全的"精修好评" |
| **B 陷害** `frame` | 白盒：目标是让我们判错 | 33 | **误报 23/33 = 69.7%（95% 单侧上界 82.5%）**，其中击穿红线到「高风险」**3 条** |
| **C 对照** `blind` | 黑盒：不知道规则 | 33 | 误报 **0/33**（上界 8.7%） |

三句必须一起读：

1. **自造集上的 0/33 不是护身符。** 同一套阈值换成对手写的样本，误报代价立刻显形。
2. **红线确实被击穿了 3 条，而我们没有改阈值去抹掉它。** 三条是同一画像：
   **真人自发组织拼单/团购的接龙**（如「身体乳拼单还差一人，私我」+ 各自改尾字）——
   它天然满足高风险档的三个条件（重复高、含商业符号、无成分实指），
   也就是说我们的「高风险」档对**买方自发的群体行为**系统性不友好。
   登记在 `samples/red_team/known_breaches.json`（含机制、可信度、下一步），
   并由 `tests/test_red_team.py::test_red_line_breaches_match_registry` 做成**棘轮**：
   多出一条（新突破没登记）红，少一条（登记过期或规则被改）也红。
   修法已写明 —— 把商业符号词典拆成「**卖方导流**」（加微/私信我/领券，指向组织化投放）
   与「**买方自发**」（拼单/凑单/上车，真人互助）两类，只有前者占比高才允许进高风险档；
   但任何 `rules.yaml` 改动都必须**重生成整套对手语料再测**（守卫强制），所以留作 v4，不在这轮偷改。
3. **规避侧 100% 应被读成我们的诚实位置**：我们不掌握账号维度数据（归因码 `ATT_NO_ACCOUNT_META`），
   一个看得见规则的白盒对手本来就该赢。产品主张从来不是"抓得准"，而是
   "**不冤枉人 + 判了就说得清凭什么**"—— P6 的归因完备性违规 **0 条**。

> 报告本身也**可重放**：`tests/test_red_team_report_reproduces.py` 把这份报告在盘上从冻结语料
> **重算一遍、必须逐字节相同**（含 3 条变异注入证明它会红）；交付版那 20 行抬头由
> `tools/make_redteam_delivery.py` 固化拼装（md5 与手工版逐字节一致），不再靠手工贴。

> 附一条发现：对手模型在「扮演水军」这一支上**大面积拒答**（26 次调用只接单 9 次 ≈ 35%，
> 最后一整轮 11/11 全拒）。`docs/REDTEAM-PROTOCOL.md` 第 6–7 节留了拒答原文、framing 变更的
> 理由（以及代价），还有我们自己"为了台账干净丢掉 27 条已生成样本"的反面教训 —— 一并留档。

## 隐私铁律

- 样本一律用程序合成图（`samples/base_neutral.jpg` / `fw_splice.jpg`，**无个人数据**，可进开源仓库）。
- 绝不把用户个人照片（尤其证件类）当默认样本，更不上传到云端 VL 接口。
- 密钥只从环境变量 / 本机 `.env` 读取，不进仓库。
